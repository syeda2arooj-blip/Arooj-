# Arooj Fatima Portfolio

A modern dark-theme portfolio for Arooj Fatima.

## Files
- `index.html` — portfolio page
- `style.css` — responsive design and hover effects
- `script.js` — mobile navigation
- `assets/profile.jpg` — profile photo
- `Arooj_Fatima_CV.pdf` — CV in PDF format

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html`.
3. Use **Live Server → Open with Live Server** (if installed), or open `index.html` directly in Chrome.

## GitHub Pages
Upload **all files and folders** to the repository root. Make sure `index.html` is in the root and `assets/profile.jpg` remains inside the `assets` folder.
Then enable GitHub Pages from:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.

The project uses relative paths, so the profile image works on GitHub Pages as long as the folder structure is preserved.

The Home section includes a **Download CV** button linked to `Arooj_Fatima_CV.pdf`.
